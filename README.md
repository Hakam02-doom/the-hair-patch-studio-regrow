# The Hair Patch Studio — Regrow layout

Website for The Hair Patch Studio — specialist non-surgical hair replacement in London. Version on the Regrow layout.

- `site/` — the static website (open `site/index.html`, or deploy the folder as-is). Vercel serves this folder.
- `build-tools/` — the scripts used to mirror the Regrow (WordPress / ThemeREX) theme and apply the brand (copy, colours, fonts, images).

Built on the Regrow (WordPress / ThemeREX) theme layout. The layout comes from a paid theme: hold a licence for it before using this site in production.
